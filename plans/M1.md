# M1 — Engine for Chains: Detailed Plan

Goal: a fully validated simulation engine for **chain topologies** (source → cables/connectors
in series, optional shunt loads at interior junctions, terminal load), producing physically
accurate TDR traces from the M0 catalog data. Everything lives in `TdrSim.Core`; no UI work
except an optional final step that feeds a real trace into the M0 smoke shell.

This milestone is where realism is won or lost: causal loss models, correct DC behavior, and
the VNA-style synthesis pipeline, each pinned by analytic closed-form tests
([PLAN.md](../PLAN.md) §5 cases 1–8, 10–12, 14).

**Definition of done**

1. All M1 validation tests green (physics cases below + engine unit tests), build clean.
2. A reference benchmark (10-segment chain, M = 32768) reports its median compute time;
   target ≤ 30 ms on this machine (assert generously at ≤ 500 ms to stay robust).
3. Optional demo: the app's placeholder plot replaced by a real computed trace of a hardcoded
   demo network (RG-58 → tee-less chain → open), proving Core↔App integration end to end.

**Out of scope** (M2+): nodal admittance solve, branches/tees/loops, chain fast-path *switch*
(M1's chain solver *becomes* the fast path in M2), editor/live updates, fault elements.

## Step 1 — Network model types (`Model/`)

Define the *general* graph model now — M2's nodal solver and M3's editor reuse it unchanged;
only the M1 solver restricts what it accepts.

```
Model/NetworkModel.cs
  NetworkModel        : immutable record; IReadOnlyList<Element> Elements
  NodeId              : readonly record struct (int Value); ground is implicit
Model/Elements.cs
  Element (abstract record)
  ├── SourcePort      (NodeId Node)                          exactly one per network
  ├── CableSegment    (NodeId A, NodeId B, CableSpec Spec, double LengthM)
  ├── Connector       (NodeId A, NodeId B, ConnectorSpec Spec)
  └── Load            (NodeId Node, LoadKind Kind, double? ROhms, double? LHenries, double? CFarads)
Model/LoadKind.cs     : Open | Short | Resistor | Capacitor | Inductor | SeriesRlc | ParallelRlc
```

`Engine/ChainExtractor.cs` walks from the source node: every interior node must join exactly
two two-ports (plus any number of shunt `Load`s); the far end terminates in loads or dangles
(treated as open, like a real unterminated cable). Output: ordered element list. A branch node
(≥3 two-ports) produces a descriptive `NotSupportedException` — lifted in M2.

**Parameter precedence decision**: the electrical pair (Z₀, VF) is primary — it determines
reflections and timing, which is what a TDR shows. Derived: `C = 1/(Z0·v)`, `L_ext = Z0/v`
(v = VF·c). The datasheet `capacitancePfPerM` becomes a cross-check: warn (not fail) if it
deviates > 5 % from the derived value. This resolves the overdetermination (Z₀, VF, C) cleanly.

## Step 2 — Loss fitting (`Engine/LossFit.cs`, `Engine/Dielectric.cs`)

From a `CableSpec` to engine coefficients, computed once and cached per spec:

1. **Attenuation fit**: least-squares `α_dB(f) = k1·√f + k2·f` (f MHz, dB/100 m) from the
   catalog points — closed-form 2×2 normal equations. Twisted-pair specs with TIA
   coefficients: sample the 3-term TIA curve (1→250 MHz, log-spaced) and fit the same 2-term
   model; the k3/√f term has no causal RLGC mapping (document: < 0.4 dB/100 m error in band).
2. **Unit conversion**: `k1' = k1/(8.686·100·√1e6)` [Np/m/√Hz], `k2' = k2/(8.686·100·1e6)`
   [Np/m/Hz].
3. **Skin coefficient**: `Rs = 2·Z0·k1'` [Ω/(m·√Hz)]; `R0` = loop DCR from the two rdc fields.
4. **Dielectric**: band tan δ = `(2·k2'/Z0)/(2π·C)` at f_ref = 100 MHz; εr from VF (εr = 1/VF²
   when `dielectricConstant` is absent). Djordjevic–Sarkar identification (m1 = 4, m2 = 12):
   `ε_d = DK·tanδ/(−Im F_d(f_ref))`, `ε_inf = DK − ε_d·Re F_d(f_ref)`, with
   `F_d(f) = ln((10^m2 + jf)/(10^m1 + jf))/((m2−m1)·ln 10)`.
   **Mandatory self-check** (unit test + debug assert): `ε_wd(f_ref) = DK·(1 − j·tanδ)` to 1e−9.

Per-frequency evaluation (`Engine/CableModel.cs`):

```
Z'(f) = R0 + √f·(1+j)·Rs + jω·L_ext                       [Ω/m]   — causal skin term
Y'(f) = jω·C_ref·ε_wd(f)/Re ε_wd(f_ref)                   [S/m]   — causal dielectric
        (Re of the product gives G(f), Im gives ω·C(f))
γl = l·√(Z'Y'),   Z0(f) = √(Z'/Y')
```

`CableEvalOptions { CausalSkin = true, CausalDielectric = true }` — the flags exist solely so
test 11 can demonstrate the non-causal precursor bug and pin the regression.

## Step 3 — Numerics kernel (`Engine/ComplexMath.cs`, `Engine/TwoPort.cs`)

Small, heavily tested helpers:

- `Expm1(Complex)` via real `Math.Exp`/`Math.Expm1` + `−2sin²(b/2)` for the cos−1 part.
- Kaiser window + Bessel `I0(x)` power series.
- **Scaled line two-port.** Work with ABCD scaled by e^(−γl) (the fold below is
  scale-invariant), eliminating overflow at any Re(γl):
  - `q = e^(−2γl)` (underflows harmlessly to 0)
  - `Ã = D̃ = (1+q)/2`
  - `B̃ = Z0·(1−q)/2`, `C̃ = (1−q)/(2·Z0)`, computing `(1−q)` as `−Expm1(−2γl)` (no
    cancellation for small γl)
  - **Exact degenerate case** `Y'l = 0` (DC with G = 0): the line is exactly a series
    resistance — `Ã = D̃ = 1, B̃ = Z'·l, C̃ = 0`. Trigger when |Y'l| = 0 or |γl| < 1e−12.
  - Small-argument branch |γl| < 1e−4: `B̃ = Z'l·(1 + (γl)²/6)·(scale ≈ 1)`, likewise C̃ —
    product forms `Z0·sinh(γl) → Z'l·sinhc(γl)` and `sinh(γl)/Z0 → Y'l·sinhc(γl)` avoid the
    infinite-Z₀ singularity entirely.
- Lumped two-ports: series Z → [1, Z; 0, 1]; shunt Y → [1, 0; Y, 1] (connectors = series R+jωL
  between two shunt jωC's; mid-chain shunt loads = shunt Y).

Property tests: stable forms vs. naive cosh/sinh at moderate arguments (relative error
< 1e−12 over |γl| ∈ [1e−3, 30]); large-argument limits (Ã→½, B̃→Z₀/2); DC degenerate case
exact; `Expm1` vs. `Complex.Exp − 1` away from the cancellation zone.

## Step 4 — Chain solver (`Engine/ChainSolver.cs`)

Fold from the termination back to the port in **homogeneous (V, I) coordinates** — no
infinities for open circuits, no overflow:

- Terminal state: open = (1, 0); short = (0, 1); load Z_L(f) = (Z_L, 1).
- Through each two-port (far→near): `(V, I) ← (Ã·V + B̃·I, C̃·V + D̃·I)`; renormalize by
  1/max(|V|,|I|) each step.
- Mid-chain shunt load at a node: `I ← I + Y_load·V`.
- Result per frequency: `Γ(f) = (V − Z_ref·I)/(V + Z_ref·I)` — well-defined even for V or I
  zero (full open/short reflection).

Load admittances/impedances per `LoadKind` with exact DC limits (capacitor → open, inductor →
short at f = 0). Frequency loop parallelized (`Parallel.For` over blocks, `γl`/`Z0` arrays per
segment precomputed vectorized).

## Step 5 — Grid + synthesis pipeline (`Engine/FrequencyGrid.cs`, `Engine/TracePipeline.cs`)

Grid auto-sizing from the network and instrument:

```
T_roundtrip = 2·Σ segment delays        (upper bound on longest echo path in a chain)
T_window    = max(6·T_roundtrip, 40·t_rise, 10 ns),  user-overridable later
dt          = t_rise/5                   (resolves the edge)
M           = nextPow2(T_window/dt), capped at 2^18 — if capped, stretch dt and set
              GridCompromised flag (surfaced as a UI badge in M4)
df = 1/(M·dt);  grid f_n = n·df, n = 0..M/2
```

Pipeline (per PLAN.md §1.4):

1. `X[n] = Γ(f_n)·H_gauss(f_n)·W_kaiser(f_n)`, where `H = exp(−(ln2/2)(f/f_3dB)²)`,
   `f_3dB = 0.34/t_rise`, Kaiser β = 6 default.
2. Hermitian mirror, Nyquist bin forced real → IFFT (FftFlat) → `h[m]`; record
   `max|Im h|` as a diagnostic (must be rounding-level).
3. `ρ[m] = Σ h[0..m]` (cumulative sum). FftFlat's inverse normalization convention is **pinned
   by a unit test**: a matched-resistor network must settle at exactly Γ(0) (DFT identity
   Σh = X[0]); if FftFlat scales differently, the pipeline compensates in one place.
4. Incident edge: same pipeline with Γ ≡ 1.
5. `TdrTrace` result: `TimeS[]`, `Rho[]`, `Volts[]` (= A·(edge+ρ)), `Ohms[]`
   (Z_ref·(1+ρ)/(1−ρ), ρ clamped to ±(1−1e−9)), `DistanceM[]` (VF·c·t/2, VF selectable,
   default = first segment), `Settled` flag (tail |h| below threshold), grid metadata.

`Engine/TdrSimulator.cs` facade: `Simulate(NetworkModel, InstrumentSettings,
SimulationSettings) → TdrTrace`. `InstrumentSettings` from catalog `InstrumentSpec` or custom;
`SimulationSettings` carries overrides (window, β, M cap) + `CableEvalOptions`.

## Step 6 — Validation tests (`tests/.../ValidationTests.cs` + unit tests)

Physics cases (numbering from PLAN.md §5). Common setup: Tek-1502C-class instrument
(300 mV/200 ps) unless stated; "plateau" readings taken ≥ 10 rise times after the edge,
mid-plateau, to stay clear of window/filter transients.

| # | Case | Assertion (tolerance) |
|---|---|---|
| 1 | 30 m RG-58, matched 52 Ω load | |ρ| < 2e−3 everywhere after incident edge; V settles to V₀·R_L/(R_L+R_g) ± 0.5 mV |
| 2 | 30 m lossless 50 Ω, open & short | edge at t = 2l/v ± 2·dt (50 % crossing); plateau ρ = ±1 ∓ 2e−3 |
| 3 | mismatch R ∈ {25, 75, 100} Ω | plateau ρ = (R−Z₀)/(R+Z₀) ± 1e−3 |
| 4 | 100 pF capacitive load | fit exp to reflected tail: τ = Z₀C ± 2 %; initial dip toward −1, final → +1 |
| 5 | 1 µH inductive load | τ = L/Z₀ ± 2 %; initial → +1, final → −1 |
| 6 | 2 pF shunt C mid-line (matched beyond) | negative dip; **area** = −Z₀C/2 ± 2 % (and invariant when t_rise doubles) |
| 7 | 10 nH series L mid-line | positive bump; area = +L/(2Z₀) ± 2 % |
| 8 | 50 Ω → 75 Ω → 50 Ω cascade | first three plateau levels match lattice partial sums (ρ₁; ρ₁+τ²ρ₂; …) ± 2e−3 |
| 10 | 300 m RG-58 (lossy), open | normalized reflected edge vs `erfc(½√(τ₀/t'))`, τ₀ = (k1'·l)²/π: max abs error < 2 % of step; verify 1/√t creep shape over [2τ₀, 50τ₀] |
| 11 | causality regression | causal: max|ρ| in (−∞, incident−3·t_rise) < 1e−4; with `CausalSkin=false`: precursor > 1e−3 (bug demonstrably reproduced) |
| 12 | Hermitian self-check | max|Im h| < 1e−10·max|Re h| on every case above (asserted centrally) |
| 14 | 100 m RG-174 + short | settles to ρ_DC = (R_loop−Z₀)/(R_loop+Z₀) for R_loop = 35.3 Ω ± 1 % — the classic "short through long cable doesn't reach −1" realism check |

Engine unit tests: LMR-400 closed-form α (0.122290√f + 0.000260·f dB/100 ft) → fit recovers
k1, k2 within 1 % and reproduces the datasheet table within ±0.05 dB/100 ft; Djordjevic–Sarkar
self-check; grid builder properties (window covers 6× round trip, M power of 2, cap behavior);
ComplexMath property tests (step 3); FFT normalization pin (step 5); ChainExtractor rejects a
branch with a clear message.

Performance smoke: 10-segment RG-58 chain, M = 32768 → warm-run median via `Stopwatch`,
written to test output; assert ≤ 500 ms.

## Sequencing

Steps 1→2→3 are independent of 4→5 only partially; recommended order: 3 (numerics, pure
functions, fastest feedback) → 2 (fits) → 1 (model) → 4 (solver) → 5 (pipeline) → 6
(validation; expect iteration here — tolerances are the negotiation between physics and
windowing) → 7. Test-first where the ground truth is analytic (steps 3, 2, and all of 6).

## Risks

| Risk | Mitigation |
|---|---|
| FftFlat inverse normalization differs from assumption | Pinned by dedicated unit test; single compensation point in pipeline |
| Window/filter transients contaminate plateau assertions | Measure mid-plateau ≥ 10·t_rise from edges; tolerances set accordingly; Kaiser β fixed at 6 in tests |
| erfc comparison sensitive to where "t = 0" of the reflected edge is taken | Define t' from the ideal arrival time 2l/v, not from a fitted edge position; document in test |
| TIA k3 term unrepresentable in causal RLGC | 2-term refit over the spec band; documented error bound; twisted-pair realism revisited in M5 if needed |
| Tolerances too tight across machines (perf test) | Physics tolerances are machine-independent; only the perf assert is generous (≤ 500 ms) with the real number logged |
| DC/degenerate numeric paths missed by happy-path tests | Dedicated property tests at f = 0, γl → 0, Re(γl) > 700, plus case 14 exercising DC settling end to end |
