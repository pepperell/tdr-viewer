# M5 — Realism Polish: Detailed Plan

Goal ([PLAN.md](../PLAN.md) §6 M5): the instrument and the network become *realistic* —
fault elements from the catalog (water ingress, crush, resistive bridge, series fault)
placeable on the canvas with closed-form-verified physics; additive Gaussian noise with
N-sweep averaging; reference-trace snapshot & compare; CSV/PNG export; and undo/redo
(deferred here from M3/M4).

Starting point: the M5 bullet's other items are already done — all five instrument presets
(§1.5) ship in [instruments.json](../src/TdrSim.Core/Catalog/Data/instruments.json) with
the M4 toolbar/inspector controls; the full §1.6 cable catalog (7) and connector catalog
(4) are in place; settling/compromised warnings and validation badges landed in M3/M4.
[faults.json](../src/TdrSim.Core/Catalog/Data/faults.json) exists and loads, but nothing
consumes `FaultSpec` yet. The engine needs **zero changes**: every fault kind maps onto
existing elements.

**Architecture decisions**

1. **Faults are an editor/document concept, not an engine concept.** The three fault kinds
   compile onto elements the solvers already handle exactly:
   - `shuntBridge` → `Load(Resistor, ROhms)` at its node;
   - `seriesFault` → `Connector` with a synthesized `ConnectorSpec` (series R, zero L/C);
   - `sectionOverride` → `CableSegment` with a spec derived from a user-chosen base cable.
   No new stamps, no new solver paths — the physics tests pin the mapping, not new math.
2. **Section-override physics: dielectric change at constant L.** Water ingress / crush
   raise the effective εr (C scales by 1/s²), which lowers *both* Z₀ and v by the factor
   s = `z0Scale`: derived spec = base `with { Z0Ohms·s, VelocityFactor·s }`. Extra
   dielectric loss (linear in f, specified in dB/100 m at 100 MHz) is added to the base
   attenuation table *points* before the existing k1/k2 fit — reusing the loss pipeline
   untouched and staying Kramers-Kronig consistent via the same Djordjevic-Sarkar path.
3. **Derived fault specs must be reference-stable across recompiles** or they silently
   destroy M4's live performance: every edit anywhere recompiles the document; a fresh
   `AttenuationTable` list each compile would break `CableSpec` record equality → new
   `CableModel` each run → spectrum-cache miss on *every* edit. A memoized
   `FaultSynthesis.SectionSpec(baseSpec, z0Scale, extraDb)` (small bounded cache keyed on
   the base-spec reference + values) returns the *same instance* for equal inputs, so the
   session caches hit exactly as for ordinary cables. A test asserts
   `SpectrumComputeCount` stays flat across repeated compiles of a fault document.
4. **Noise is display-stage post-processing, not engine physics.** `TraceNoise.Apply`
   adds seeded Gaussian noise (σ_v = RMS/√sweeps) to Volts/Rho and recomputes Ohms from
   the clamped noisy ρ — after `Simulate`, outside every cache and bitwise test. Applied
   at publish time in the shell, with a fresh seed per published trace, so live sweeps
   shimmer like a real repetitive-sweep instrument; off (0 mV) bypasses entirely.
5. **Undo/redo is snapshot-based over `ProjectDocument`.** The document layer already
   round-trips the whole editor state (including node positions) and `ToDocument()`
   already runs on every mutation — so undo = restore a previous document. Mutation
   bursts (slider drags, node drags) coalesce into one undo step via a quiet-period
   timer; snapshots are the serialized JSON (identity-compared to skip no-op pushes),
   capped at 100. No per-operation command objects, no editor rework.
6. **Schema bumps to 2, additively.** New document fields: fault nodes
   (`FaultKind`, `FaultPresetId`, `Z0Scale`, `ExtraDielectricLossDbPer100m`, reusing
   `CablePresetId`/`LengthM`/`ROhms`) and instrument noise
   (`NoiseRmsMillivolts`, `AveragingSweeps`). `Deserialize` accepts versions 1 and 2
   (v1 is a strict subset); `Serialize` writes 2; ≥3 still rejected with the clear
   message. Old files load unchanged; the embedded default document stays as-is.

**Definition of done**

1. All 150 existing tests plus the new Core tests green; build clean (warnings as errors).
2. All four fault presets drag from a new palette group, edit in the inspector, compile,
   and reproduce closed forms: series-R plateau ρ = R/(R+2Z₀); bridge dip
   ρ = −Z₀/(2R+Z₀); section-override dip level from the lattice sums with duration
   2l/(s·VF·c); DC levels exact. Fault documents round-trip through save/load.
3. Fault edits stay live: spectrum cache hits across recompiles of an unchanged fault
   section (asserted via session counters).
4. Noise: measured RMS on a matched-load trace matches the setting; 16-sweep averaging
   reduces it 4×; seeded determinism for tests; 0 mV adds zero overhead; settings persist
   in the project file and validate (negative RMS / sweeps < 1 fatal).
5. Undo/redo: Ctrl+Z / Ctrl+Y + toolbar buttons with correct enablement; covers graph,
   fault, and instrument edits; a slider/node drag is one step; restore keeps the file
   path, marks dirty, and live-updates the trace.
6. Reference compare: snapshot the displayed trace, render it dimmed behind the live one
   in every axis mode, survive live updates and unit switches, clear on demand
   (session-only, not persisted).
7. Export: CSV (time_ns, distance_m, rho, volts_mV, ohms; invariant culture — generator
   unit-tested in Core) and PNG via ScottPlot; both disabled until a trace exists.
8. UIA smoke extended: noise edit triggers a fresh run; Undo restores the rise-time
   readout; reference toggle works; process stays alive.

**Out of scope** (M6: bounce diagram, trace↔canvas cross-highlighting, layer peeling).
Also deferred: custom cable creation beyond Z₀/VF overrides (datasheet-style / raw RLGC
entry, PLAN §1.2), per-division vertical scale presets, persisting reference traces.

## Step 1 — Fault document model + compiler mapping (`Core/Project/`, `Core/Catalog/`)

- `DocumentNodeKind.Fault` + `enum FaultKind { SectionOverride, ShuntBridge, SeriesFault }`
  stored on the node (self-contained — ports and compilation never need the preset).
  `DocumentPorts.For` gains the fault case: SectionOverride/SeriesFault → [A, B],
  ShuntBridge → [P]. `FaultPresetId` is display/defaults-only; the compiler ignores it.
- `FaultSynthesis` (Core/Catalog): memoized `SectionSpec(base, z0Scale, extraDb)` per
  decision 2/3, and `SeriesConnectorSpec(rOhms)` (plain — `ConnectorSpec` is all value
  fields, record equality already works).
- `DocumentCompiler.EmitElements` handles Fault per kind. New fatal issue kind
  `InvalidFaultValues`: z0Scale ≤ 0, derived VF outside (0, 1], extra loss < 0,
  bridge/series R ≤ 0; existing kinds reused where natural (`UnknownPresetId` for the
  base cable, `NonPositiveLength`, `SelfLoop`).
- Schema v2 per decision 6 (`CurrentSchemaVersion = 2`, accept {1, 2}).

Tests: document round-trip with all three fault shapes; v1 file still loads; v3 rejected;
ports/union-find wiring (bridge at a tee merges correctly); every `InvalidFaultValues`
case; `FaultSynthesis` reference-stability (`Assert.Same` across calls) and the
cache-hit-across-recompiles counter test from DoD #3.

## Step 2 — Fault physics pinned to closed forms (`DocumentCompilerTests` style)

On lossless base cable via documents, chain path where applicable:
- Series fault R = 10 Ω mid-line, matched termination: plateau at the fault
  ρ = R/(R+2Z₀) ± 1e−3; DC settles to the exact (R_g + R + R_L) divider ± 1e−9.
- Bridge 470 Ω mid-line, matched continuation: dip to ρ = −Z₀/(2R+Z₀) ± 1e−3.
- Section override s = 0.7, 2 m on a 30 m feed: first dip to (s−1)/(s+1) ± 2e−3; return
  edge at Δt = 2·2/(s·VF·c) (crossing-time helper, ± dt); plateau ladder from the
  two-interface lattice sums (test-8 machinery); extra-loss variant shows strictly more
  round-trip attenuation than the clean section (inequality, not exact).
- Water-ingress preset defaults end-to-end: compile default params from
  [faults.json](../src/TdrSim.Core/Catalog/Data/faults.json), trace settles, Hermitian
  self-check passes.

## Step 3 — Noise + averaging (`Core/Engine/TraceNoise.cs`)

- `TraceNoiseSettings(double RmsVolts, int Sweeps)`; `TraceNoise.Apply(trace, settings,
  seed)` → new `TdrTrace` (Box-Muller Gaussian on Volts; Rho offset by noise/A; Ohms from
  clamped noisy ρ; TimeS/DistanceM/Grid shared, Settled/flags carried; `RmsVolts == 0` →
  returns the input instance).
- `InstrumentDocument` gains `NoiseRmsMillivolts`/`AveragingSweeps` (nullable = off/1);
  compiler validates (fatal `InvalidInstrumentValues` when negative / sweeps < 1) and
  surfaces a resolved `TraceNoiseSettings?` on `DocumentCompilation`.
- Shell applies it in `PublishTrace` (fresh seed per publish, previews included — a live
  repetitive sweep); `Refresh` path identical.
- Inspector (instrument template): "Noise RMS (mV)" box + "Averaging" combo (1/4/16/64/256).

Tests: RMS of (noisy − clean) on a matched 50 Ω trace ≈ σ ± 10 %; sweeps = 16 → ≈ σ/4;
same seed → bitwise-identical output; seed varies → differs; zero RMS → `Assert.Same`;
DC/Settled flags untouched; document round-trip + validation cases.

## Step 4 — Undo/redo (`App/Shell/`)

Snapshot machinery per decision 5, entirely in `ShellViewModel`:
- `_lastCommitted` = serialized current document, refreshed when a 400 ms quiet-period
  timer fires after a mutation burst; first mutation of a burst pushes `_lastCommitted`
  onto the undo stack (skip if JSON-identical) and clears redo. Cap 100.
- `UndoCommand`/`RedoCommand` (+ CanExecute → toolbar ↶ ↷ buttons, `Ctrl+Z`/`Ctrl+Y`
  window bindings): pop, push the opposite stack, restore via the existing
  `LoadDocument` path under the `_loading` guard — preserving `_filePath`, forcing
  dirty, recompiling (which live-submits). New/Open/Save-As clear both stacks.
- Known limits documented in code: selection and viewport are not restored.

Manual-heavy by nature, but the stack logic itself stays testable: extract
`UndoStack` (push/coalesce/cap/clear semantics over strings) into a tiny Core-free class
in App… no — put it in `Core/Project/UndoStack.cs` so it gets unit tests (push dedupe,
cap eviction, undo/redo sequencing, redo cleared on new push).

## Step 5 — Reference-trace compare (`App/Plot/`)

- `TracePanelViewModel`: `ReferenceTrace` (TdrTrace?), `SetReferenceCommand` (snapshots
  the currently displayed trace, noise and all), `ClearReferenceCommand`; "Ref" set/clear
  buttons in the panel bar (set disabled with no trace).
- View renders the reference as a second Signal — thinner, semi-transparent gray, added
  *before* the live signal — rebuilt through the same mode/VF conversions on every
  replot. Reference keeps its own grid/length (different dx is fine). Cursors keep
  sampling the live trace only.

## Step 6 — CSV/PNG export (`Core/Engine/TraceExport.cs` + `App/Plot/`)

- `TraceExport.WriteCsv(TextWriter, trace, displayVf)` in Core: header
  `time_ns,distance_m,rho,volts_mV,ohms`, invariant culture, distance from the panel's
  display VF — unit-tested (column math on a known trace, culture independence under a
  forced de-DE culture).
- Panel bar "CSV" / "PNG" buttons (disabled until a trace exists): `SaveFileDialog` in
  the panel code-behind; PNG via `Plot.SavePng` at the control's current pixel size
  (×`DisplayScale`), verified at build time like the other ScottPlot APIs.

## Step 7 — Editor UI for faults + smoke pass

- `FaultNodeViewModel` (LoadNodeViewModel pattern: `FaultKind` property name avoids the
  base `Kind` collision; params default from `FaultDefaults`; titles like
  "Water ingress · 2 m", "Bridge 470 Ω"); canvas node template; palette "Faults" group;
  inspector template with per-kind visibility (UsesSection/UsesBridge/UsesSeries) — base
  cable dropdown + length/scale/extra-loss boxes for sections, single R box otherwise.
- Full suite; UIA smoke extended from M4's script: set the noise RMS TextBox via
  ValuePattern (inspector shows the instrument at startup) → status shows a fresh run;
  move the rise slider then invoke the Undo toolbar button → rise readout returns to
  200 ps; toggle Ref on/off; process alive. (Palette drag-drop stays out of UIA reach —
  fault placement is covered by the compiler/physics tests and the manual checklist.)
- Manual checklist: drop each fault on the demo tee and sanity-check the trace shape;
  noise shimmer at 2 mV/1 sweep vs calm at 256 sweeps; undo a node drag; reference
  overlay vs a length change; CSV opens in a spreadsheet; PNG matches the screen.

## Sequencing

1 → 2 (document/compiler then physics, pure Core, test-first) → 3 (noise, Core+document)
→ 4 (undo, independent of 1–3) → 5/6 (panel features, independent of each other) → 7
(editor UI last, then smoke). 4 can run any time after schema v2 exists; 5/6 any time.

## Risks

| Risk | Mitigation |
|---|---|
| Derived fault specs break session caching (every edit becomes a cold run — silent UX regression) | Memoized `FaultSynthesis` returning reference-stable specs; counter-asserted cache-hit test (DoD #3) |
| Undo stack flooded by per-pixel drag mutations | Quiet-period coalescing (400 ms) + JSON-identity dedupe + 100 cap; `UndoStack` semantics unit-tested in isolation |
| Noise contaminating caches or bitwise guarantees | Applied strictly post-`Simulate` at publish; engine, session, and all M4 tests untouched; 0 mV returns the input instance |
| Schema v2 breaks old files or confuses old builds | v1 accepted forever (additive fields only); ≥3 keeps the clear "unsupported version" message; round-trip tests for both versions |
| Section-override physics choice (VF scales with Z₀) surprises later | Decision 2 documents the constant-L dielectric rationale; timing test pins v′ = s·VF so any change breaks loudly |
| `SaveFileDialog` unreachable from UIA smoke | CSV generator unit-tested in Core; PNG on the manual checklist |
| Reference overlay with a mismatched grid (different M/dt after edits) | Overlay carries its own dx/offset — no resampling; covered in manual checklist across unit switches |
| PS 5.1 mojibake when editing files | All file edits via the Write/Edit tools only |
